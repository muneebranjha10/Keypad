## Installation

1. Install **GlassDialer-v1.8.1.apk**.
2. Open the app and continue to the setup guide.
3. Enable Glass Dialer in LSPosed and select Samsung Phone (`com.samsung.android.dialer`).
4. Enable Samsung Dark mode, force stop Phone and reopen it.

**Requirements:** Samsung Phone, compatible firmware and working LSPosed. Developed around One UI 9. Other firmware, latest footer behavior and sustained 120 Hz are not independently verified. Disable the module if dialing is affected.
